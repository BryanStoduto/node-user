# 👤 User Registration System

A simple system to register, list, edit, and delete users, with encrypted passwords.

## 🚀 Features

* Register new users
* List all users
* Edit user information
* Delete users
* Encrypted passwords using **Bcrypt**

## 🛠️ Technologies

* Node.js
* Express
* Bcrypt
* HTML, CSS, and JavaScript

## ▶️ How to run

1. Install dependencies:

```bash
npm install express bcrypt cors
```

2. Start the server:

```bash
node server.js
```

3. Open the index.html file in your browser.
